## About Me

I am a cybersecurity and application security leader with **16+ years of experience** across software engineering, infrastructure and enterprise security architecture, focused on mission-critical payment systems.

I began my career as a software developer in Chennai in 2010 and progressed through software architecture and infrastructure into information security. Today I serve as **IT Application Security Manager at Novalnet AG**, where I am responsible for the security of a large-scale payment platform.

- 🔐 Accountable for **PCI DSS Level 1** (currently v4.0.1) across the full payment ecosystem and **SOC 2 Type II** certification since 2018
- 🏗️ Secure-by-design architecture, threat modelling, secure SDLC and risk-based control design
- 🌐 High-availability, multi-data-centre infrastructure, network segmentation and Linux platform hardening
- 🤝 Building shared security ownership between development, operations and compliance teams
- 🎯 Open to **Enterprise Security Architect**, **Head of Security** and **CISO** opportunities
